# Retail Sales Prediction

## Overview

This project uses Machine Learning to predict retail sales based on historical retail data.

## Features

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Random Forest Regression Model
* Sales Prediction

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Project Structure

* Retail_Prediction.ipynb : Main notebook
* dataset.csv : Dataset used for training
* README.md : Project documentation

## How to Run

1. Clone the repository.
2. Install required libraries.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Run all cells.
